Contains Duplicate (LeetCode 217) explained step by step in C++, from O(n²) brute force to an O(n) hash set solution.

What you'll learn:
• Brute force: compare every pair. O(n²) time, O(1) space
• Sort + check neighbors: equal values end up side by side. O(n log n) time, O(1) extra space
• Hash set: one pass, stop at the first repeat. O(n) time, O(n) space
• The trade-off: sorting saves memory, hashing saves time
• Edge cases: one number, negatives, extreme values, repeats far apart
• The pattern: "have I seen this before?" → hash set
